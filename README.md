# 📊 Git Demo — Sales Analysis (School Supplies Store)

A practice project designed to **demonstrate Git commands in class**.

Contains:
- `analysis_notebook.ipynb`: Jupyter notebook with a basic sales analysis.
- `sales_data.csv`: synthetic sales data (date, product, units, price).

## Goal

Use this repo as a base to practice live:

- `init`, `clone`
- `status`, `add`, `commit`
- `log`, `diff`
- `branch`, `switch` / `checkout`, `merge`
- merge conflicts
- `.gitignore`
- `remote`, `push`, `pull`
- `stash`
- `revert` vs `reset`

See **`GIT_DEMO_GUIDE.md`** for the full step-by-step sequence.
